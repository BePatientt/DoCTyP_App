# Проверки диагностической версии 1.0

Дата: 2 ноября 2026.

## Выполнено в среде сборки

- Android SDK API 35, Gradle 8.9 с проверкой SHA-256, AGP 8.7.3, Kotlin 2.0.21, Java 21; JVM target 17.
- `scripts/bootstrap-cloud.sh` выполнен после установки инструментов: повторная настройка и сборка успешны.
- `:app:assembleDebug` — успешно, создан устанавливаемый debug APK.
- `apksigner verify --verbose` — успешно, APK подписан (v2).
- `:app:testDebugUnitTest` — 11 тестов, 0 ошибок/провалов/пропусков: 5 тестов ScanSession; 3 теста Reports/ReportStore на Robolectric API 35; 3 теста Activity на Robolectric API 35.
- Проверены отмена и устаревшие callbacks, отсутствие обнаружения, повторное сканирование, уход с экрана, состояния без NFC/с выключенным NFC, сохранение и восстановление частичного результата с TagLostException, переименование без дублирования, удаление, текстовый и JSON-сериализованный отчёт.
- `:app:lintDebug` — успешно, 0 ошибок, 6 предупреждений: экспортный флаг receiver для minSDK31, правила переноса/backup, отсутствие отдельной иконки, 3 замечания к локализации строк. Целевой физический Android 15 поддерживает используемый флаг receiver.
- Статическая проверка: отсутствуют INTERNET permission, HCE-service, transceive/APDU, аутентификация MIFARE, запись блоков/страниц, writeNdefMessage, format, makeReadOnly. NFC I/O — только отдельная NDEF-проверка вне UI-потока с закрытием соединения.

Robolectric — JVM-модель Android, а не физическое устройство и не системный эмулятор. Исключение потери метки в тесте отчёта имитируется: радиопотеря на настоящем брелоке не проверялась.

## Требует физического телефона

- Реальное обнаружение брелока и возвращаемый список технологий на Nothing Phone (1).
- NDEF-проверка, аппаратная потеря метки и устойчивость повторного прикладывания.
- Физическая работа антенны, NFC-контроллера и прошивки Android 15.
- Выбор получателя в системном «Поделиться» и сохранение через файловый провайдер на конкретном телефоне.
- Совместимость со считывателем и возможность мобильного credential. Проход в офис не реализован и не проверен.

Содержимое страниц developer.android.com не удалось получить из-за 403 сетевого прокси. Публичные API сверены по официальным исходникам/Javadoc Google SDK API35; подробности и ссылки — NFC-API.md.

## Системный эмулятор

Установлены Android Emulator 37.2.13 и официальный образ API35 default x86_64. AVD: экран 1080×2400, профиль Pixel 6. В машине отсутствует /dev/kvm; запускался программный режим `-accel off`. ADB подключился, но за более чем 5 минут `sys.boot_completed=1` не получен. Ранние попытки установки отклонены неготовыми службами package/storage; успешная установка и запуск приложения на эмуляторе не подтверждены. Эмулятор остановлен. Проверку внешнего вида и системных диалогов на полноценном Android нельзя считать пройденной; Activity проверена только Robolectric-тестами. Это ограничение проверки среды, а не установленная ошибка APK.
