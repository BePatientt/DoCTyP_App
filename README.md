# DoCTyP · NFC

Локальная диагностика офисного брелока для Nothing Phone (1), Android 15. Kotlin, штатные Android Views с Material-темой, API 31+, target/compile SDK 35. Аккаунт и сервер не нужны. Это диагностическое приложение; проход в офис и копирование пропуска не реализованы и не подтверждены.

## Установка

1. Скачайте `DoCTyP-debug.apk` на телефон и откройте файл.
2. Если Android предложит — разрешите установку из этого источника (браузера/файлового менеджера). После установки разрешение можно отключить.
3. Откройте «DoCTyP · NFC», включите NFC через кнопку настроек. Разблокируйте телефон.

Это debug APK для личного тестирования, подписанный отладочным ключом. При смене ключа для обновления может потребоваться удаление старой версии, что удалит её локальные отчёты: экспортируйте их заранее.

## Сканирование

1. Нажмите «Начать сканирование · 20 с».
2. Приложите брелок к задней стороне телефона, медленно перемещайте по верхней и центральной части. Удерживайте 2–3 секунды; при необходимости снимите чехол. Оставьте приложение на экране.
3. Сначала сохраняются UID (если предоставлен), длина, технологии и сведения об устройстве. Затем читаются доступные параметры. Базовый режим не проверяет NDEF и не читает защищённую память.
4. Сохраните результат и задайте имя, например «Мой офисный брелок — базовый».
5. Уберите брелок. Нажмите «Отдельная проверка NDEF», приложите снова, сохраните второй отчёт. Отсутствие NDEF не означает пустой или повреждённый пропуск.
6. «Экспорт / Поделиться» → JSON или Текст → «Сохранить в файл» либо «Поделиться». Отправка происходит только по вашему действию. Отчёты содержат UID: выбирайте получателя осознанно.

Если метка не обнаружена, сохраните и этот результат. Повторите несколько положений. Необнаружение не доказывает частоту 125 кГц, неисправность или отсутствие чипа. Уход с экрана останавливает сканирование; вернувшись, запустите его снова. Дополнительное чтение ограничено 8 секундами. Повторное прикладывание обрабатывается в новой сессии.

Список «Сохранённые отчёты» позволяет открыть, переименовать или удалить запись. Последний результат сохраняется отдельно для восстановления после закрытия. Удаление сохранённой записи удаляет соответствующий последний результат и временные экспортные файлы. Копии, уже сохранённые в другом приложении/папке, нужно удалить там самостоятельно.

## Что прислать для следующего этапа

Пришлите два JSON-отчёта: базовый и NDEF, либо отчёты о необнаружении. Укажите, было ли обнаружение хотя бы при одном положении брелока. При наличии — модель/фото маркировки офисного считывателя, без персональных данных. Фото корпуса брелока не устанавливает модель чипа.

По результатам можно отделить установленную технологию от неизвестных параметров. Чтение и HCE не равны совместимости со считывателем. Даже IsoDep не раскрывает протокол доступа, ключи и полномочия. Может потребоваться выпуск/регистрация мобильного credential системой доступа. До этого кнопки «Открыть дверь» нет.

## Сборка

Нужны JDK 17 или 21, Android SDK с `platforms;android-35` и `build-tools;35.0.0`. Задайте ANDROID_HOME или создайте игнорируемый `local.properties` с `sdk.dir=/путь/к/sdk`.

```sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Тесты: `app/build/test-results/testDebugUnitTest`. Lint: `app/build/reports/lint-results-debug.html`.

Если используется сетевой прокси, JVM Gradle требует `-Dhttps.proxyHost=… -Dhttps.proxyPort=… -Dhttp.proxyHost=… -Dhttp.proxyPort=…`. Не отключайте TLS-проверку. Для Robolectric сетевые настройки нужны также тестовой JVM (или предварительно заполненный кэш Android runtime).

Документация и ограничения API: [docs/NFC-API.md](docs/NFC-API.md). Результаты проверки этой сборки: [docs/VALIDATION.md](docs/VALIDATION.md).
